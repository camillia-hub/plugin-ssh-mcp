# SSH MCP

Runs shell commands on a remote host over SSH. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/ssh-mcp-server

Installs from the Camillia hub as `ssh-mcp-6bcd6d`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
